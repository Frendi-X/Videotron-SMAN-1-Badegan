# 📁 Videotron SMAN 1 Badegan – Configuration Files

Repositori ini berisi kumpulan file konfigurasi yang digunakan untuk pengaturan (*setting*) videotron di lingkungan **SMAN 1 Badegan**. Repositori ini mencakup konfigurasi IC driver LED, IC decoder, file pendukung pengaturan panel LED, serta dokumentasi visual terkait koneksi dan pemetaan panel videotron.

---

## 🧩 Isi dan Fungsi File

- **`Configuration LS9931 ICN2018.zip`**  
  Berisi file konfigurasi IC **LS9931** dan decoder **ICN2018** yang digunakan sebagai referensi dalam proses konfigurasi panel LED videotron.

- **`image/`**  
  Folder dokumentasi visual yang berisi gambar koneksi panel, pemetaan LED (*LED Mapping*), layout pemasangan, dan dokumentasi teknis lainnya.

- **`README.md`**  
  Dokumen utama yang menjelaskan isi repositori, fungsi file konfigurasi, serta catatan teknis dalam proses pengaturan videotron.

### 🎯 Tujuan Konfigurasi

File konfigurasi disediakan sebagai referensi teknis untuk membantu proses pengaturan panel videotron agar sesuai dengan karakteristik perangkat keras yang digunakan.

Konfigurasi yang tepat perlu disesuaikan dengan jenis modul LED, IC driver, IC decoder, kartu penerima (*receiving card*), sistem kontrol, serta susunan panel yang terpasang.
